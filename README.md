# Apex Tech — Modern Digital Studio & Website Builder

Apex Tech is a high-performance, modern digital agency web application crafted with React 19, TypeScript, Tailwind CSS, and Framer Motion. Featuring interactive project inquiry discovery, live portfolio showcase, and responsive mobile-first design.

---

## 🚀 Features

- **Modern Responsive Design**: Built with high-contrast luxury UI/UX inspired by contemporary web builders.
- **Interactive Intake & Consultation**: Seamless consultation booking modal and contact forms with custom validation.
- **Dynamic Case Studies & Portfolio**: Categorized project filter gallery with detailed metrics and imagery.
- **Smooth Animations**: Powered by Framer Motion for buttery smooth page interactions, laser line separators, and back-to-top scroll indicators.
- **Fast & Lightweight**: Zero unnecessary bloat, fully optimized for 98+ Core Web Vitals.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn / pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/its-sartaj/Apex-Tech.git
   cd Apex-Tech
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🌐 Deployment

The project can be deployed instantly on modern hosting providers:
- **Vercel**: Import repository and deploy directly (Framework Preset: `Vite`).
- **Netlify**: Connect GitHub repository, build command: `npm run build`, publish directory: `dist`.
- **GitHub Pages**: Build output in `dist` folder.
